# MCP Servers Catalog

**Total: 55 MCP servers** from [aitmpl.com/mcps](https://www.aitmpl.com/mcps/)

Install any MCP server via NPM:
```bash
npm install @aitmpl/mcp-<category>-<server-name>
```

Or use Claude Code:
```
/mcp add <server-name>
```

**Need to add more MCPs?** Visit [aitmpl.com/mcps](https://www.aitmpl.com/mcps/) and drill into each category. Submit a PR to update `mcp/catalog.json` with new servers.

## Adding New MCPs

To add more MCP servers from [aitmpl.com/mcps](https://www.aitmpl.com/mcps/):

1. Visit https://www.aitmpl.com/mcps/
2. Drill into each category (DevTools, Databases, APIs, etc.)
3. Extract server metadata: name, description, install command, download count
4. Update `mcp/catalog.json` with new entries
5. Regenerate this catalog (if script available)
6. Submit PR

**Manual update structure for `mcp/catalog.json`:**

```json
{
  "category-name": {
    "count": 1,
    "display_name": "Category Display Name",
    "servers": [
      {
        "name": "server-name",
        "description": "One-line description",
        "category": "category-name",
        "install": "npm install @aitmpl/mcp-category-server-name",
        "url": "https://www.aitmpl.com/component/mcp/category/server-name",
        "downloads": 100,
        "verified": true
      }
    ]
  }
}
```
