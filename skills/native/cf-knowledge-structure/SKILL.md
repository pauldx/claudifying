# Knowledge Structuring Skill

Organizes unstructured information into clear frameworks, bullet points, or structured notes for easier understanding and application.

## Activation

- User says "organize this", "structure these notes", "categorize this"
- User provides messy braindump needing logical ordering
- User wants framework or mental model from raw ideas

## Process

### 1. Identify Topics
- Extract major themes or categories from input
- Note relationships between ideas

### 2. Group and Hierarchy
- Cluster related ideas under parent categories
- Establish logical ordering (chronological, priority, dependency)

### 3. Format
- Present as structured framework with clear headings
- Use bullets, numbering, or indentation for hierarchy

## Output

- Structured framework with clear categories
- Hierarchical bullet points
- Logical flow from general to specific
- No ambiguity — each item has clear placement
