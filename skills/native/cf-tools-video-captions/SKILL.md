# Caption & Subtitle Formatter

Formats captions and subtitles for readability, timing, and accessibility across videos.

## Activation

- User says "format captions for", "create subtitles", "SRT file", "caption this"
- User has transcript needing caption-style formatting
- User wants timed subtitles for video content

## Process

### 1. Line Breaking
- Max 2 lines per caption block
- Break at natural phrase boundaries
- Keep each line under 42 characters

### 2. Timing
- 1-6 seconds per caption block
- Match to speech rhythm
- No overlap between blocks

### 3. Readability
- Simple, clear text
- Punctuation for pacing
- Speaker identification where needed

## Output

- Formatted caption blocks
- SRT or VTT format if requested
- Timing cues aligned to content
- Readable on mobile screens
