# Infographic Builder

Turns textual content into structured infographic formats suitable for reports, presentations, and educational materials.

## Activation

- User says "make an infographic", "visual summary", "step-by-step visual"
- User needs data presented visually for slides or reports
- User wants process or stats in visual-friendly format

## Process

### 1. Extract Key Points
- Identify core data, steps, or stats from input
- Prioritize most impactful information

### 2. Organize Visually
- Group into sections (header, body sections, footer)
- Assign visual hierarchy (size, order, emphasis)

### 3. Format
- Use numbered steps, icons/markers, stat callouts
- Keep text minimal per section

## Output

- Sectioned layout with headings
- Bullet or step representation
- Visual cues (icon suggestions, color coding notes)
- Readable without clutter
