# Source Validation Skill

Validates the credibility of information sources, highlighting reliability, relevance, and potential biases.

## Activation

- User says "is this source reliable", "validate these references", "check credibility"
- User provides claims needing verification
- User wants bias analysis on information

## Process

### 1. Evaluate Source
- Check author credentials, publication reputation
- Assess recency and relevance
- Note potential conflicts of interest

### 2. Detect Bias
- Identify framing, selective reporting, or loaded language
- Note funding or affiliation that may influence conclusions

### 3. Score and Summarize
- Rate reliability (high/medium/low with reasoning)
- Flag specific concerns
- Suggest better alternatives if available

## Output

- Source reliability rating with reasoning
- Bias indicators noted
- Key verified insights extracted
- Alternative sources suggested where appropriate
