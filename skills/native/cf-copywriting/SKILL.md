# Structured Copywriting Skill

Produces persuasive, well-structured copy with strong hooks and clear calls to action for marketing, articles, and social media.

## Activation

- User says "write copy for", "create a hook", "marketing text", "ad copy"
- User needs landing page text, social post, email subject lines
- User wants persuasive, conversion-focused writing

## Process

### 1. Hook
- Craft attention-grabbing opening
- Pattern-interrupt or curiosity-driven first line

### 2. Body Structure
- Organize main points clearly
- Use short paragraphs, bullets where appropriate
- Build logical case or narrative

### 3. Call to Action
- Include clear, actionable CTA
- Match urgency to context

## Output

- Sectioned flow: hook, body, CTA
- Concise and readable
- No unnecessary filler or overcomplicated language
- Platform-appropriate length and format
