# Video Script Generator

Generates video scripts with hooks, structured sections, pacing, and call-to-actions optimized for engagement and retention.

## Activation

- User says "write a script for", "video script", "YouTube script", "narration for"
- User planning short-form (Reels/TikTok) or long-form (YouTube) video
- User needs structured content with timing awareness

## Process

### 1. Hook (0-5s)
- Bold statement, question, or pattern interrupt
- Immediately communicate value proposition

### 2. Content Sections
- Organized main points with transitions
- Each section has one clear idea
- Pacing varies to maintain attention

### 3. Closing
- Summary of key takeaway
- Clear CTA (subscribe, comment, link)
- Optional teaser for next content

## Output

- Timestamped or sectioned script
- Hook clearly marked
- Transition notes between sections
- CTA placement noted
- Estimated duration
