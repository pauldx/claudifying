# Claudifying Project Overview

**Purpose:** Global collection of Claude plugins, hooks, skills, prompts, and commands for community use.

**Vision:** Centralized, production-ready extensions for Claude Code that anyone can use and contribute to.

## Goals

1. **Accessibility** — Easy for anyone to discover and use Claude extensions
2. **Quality** — Production-ready, well-documented, tested extensions
3. **Community** — Lower barrier to contribution, encourage sharing
4. **Sustainability** — Clear guidelines, licensing, maintenance structure

## Scope

### In Scope
- ✅ Plugins (Claude Code plugins)
- ✅ Hooks (event-driven automation)
- ✅ Skills (reusable task modules)
- ✅ Prompts (system prompts, templates)
- ✅ Commands (CLI tools, workflows)
- ✅ Examples (integration guides, samples)
- ✅ Documentation (READMEs, guides)

### Out of Scope
- ❌ Proprietary/commercial extensions
- ❌ GPL-licensed code (unless clearly disclosed)
- ❌ Undocumented extensions
- ❌ Security vulnerabilities or exploits

## Key Principles

1. **MIT-First** — Default to MIT license for consistency
2. **Community-Driven** — Open contributions welcome
3. **Well-Documented** — Every extension has clear README
4. **Tested** — Extensions must be working and tested
5. **Transparent** — Dependencies and licenses disclosed clearly

## Success Metrics

- Number of extensions (target: 50+ first year)
- Active contributors
- Download/usage stats
- Community satisfaction
