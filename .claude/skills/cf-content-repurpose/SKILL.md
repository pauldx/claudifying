# Content Repurposing Engine

Transforms blogs, notes, articles, and long-form content into varied formats for different channels while preserving the core message.

## Activation

- User says "turn this into a thread", "make a video script from this"
- User wants content adapted for Twitter/LinkedIn/YouTube/newsletter
- User provides long-form and wants short-form derivatives

## Process

### 1. Analyze Source
- Identify key ideas, supporting points, and core message
- Note tone, audience, and original format

### 2. Identify Target Format
- Ask or infer target platform/format
- Options: thread, short video script, summary, LinkedIn post, newsletter blurb, carousel outline

### 3. Transform
- Rewrite in target format conventions
- Preserve meaning and tone
- Add platform-appropriate hooks, structure, length

## Output

- Platform-specific content with proper formatting
- Engaging headlines/hooks for each format
- Consistent tone across all outputs
- Format matches channel style (character limits, paragraph length, structure)
