# Tone & Style Enforcer

Keeps all generated content aligned with defined style guidelines or brand voice. Ensures consistency across multiple outputs.

## Activation

- User says "match this tone", "use my brand voice", "make it consistent"
- User provides style guide or tone reference
- User wants multiple outputs to sound like the same author/brand

## Process

### 1. Identify Target Tone
- Extract from user's style guide, example text, or explicit instructions
- Dimensions: formal/casual, technical/simple, warm/neutral, playful/serious

### 2. Apply Tone
- Rewrite or generate content matching the defined voice
- Adjust word choice, sentence structure, formatting

### 3. Verify Consistency
- Check for style deviations within the output
- Ensure language, structure, and formatting align

## Output

- Text aligned with style guide
- Clean, professional formatting
- No deviation from selected tone
- Clarity maintained regardless of style constraints
