# Deep Research Synthesizer

Synthesizes insights from large datasets or text, filters irrelevant data, identifies patterns, and produces actionable summaries.

## Activation

- User says "synthesize this", "what are the key insights", "analyze this research"
- User provides large text corpus needing distillation
- User needs patterns or trends identified from multiple sources

## Process

### 1. Filter
- Remove low-value, redundant, or irrelevant content
- Identify signal vs noise

### 2. Identify Patterns
- Find recurring themes, contradictions, or trends
- Note frequency and strength of patterns

### 3. Structure Output
- Key insights (ranked by importance)
- Supporting evidence for each
- Actionable recommendations

## Output

- Ranked key insights with evidence
- Pattern summary
- Actionable takeaways
- No generic filler — utility-focused only
