# Long-Form Summary Compressor

Reduces complex, dense content into digestible summaries while keeping essential ideas intact.

## Activation

- User says "summarize this", "TL;DR", "compress this", "key points only"
- User provides long text and wants quick-consumption version
- User needs executive summary or brief

## Process

### 1. Identify Main Points
- Extract core arguments, insights, and conclusions
- Distinguish essential from supporting detail

### 2. Remove Redundancy
- Cut repeated ideas, filler, and tangential content
- Preserve unique information only

### 3. Produce Summary
- Format as concise paragraph or bullet points (match user preference)
- Maintain original meaning and nuance
- Keep actionable elements visible

## Output

- Concise paragraph or bullet list
- No missing critical info
- No filler or padding
- Readable without original context
