# Competitive Intelligence Skill

Compares products, protocols, or tools to provide structured analysis of strengths, weaknesses, and opportunities.

## Activation

- User says "compare these", "competitor analysis", "SWOT for", "how does X vs Y"
- User evaluating market positioning or feature gaps
- User needs structured decision support for tool/product selection

## Process

### 1. Identify Subjects
- Define what's being compared (products, tools, protocols)
- Establish comparison dimensions (features, pricing, UX, performance)

### 2. Compare
- Feature-by-feature analysis
- Strengths and weaknesses per subject
- Market positioning and differentiation

### 3. Recommend
- Highlight opportunities and risks
- Provide actionable recommendation based on user's context

## Output

- Comparison table or bullet matrix
- Strengths/weaknesses per subject
- Key differentiators highlighted
- Actionable recommendation with reasoning
