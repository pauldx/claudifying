# UI/UX Layout Advisor

Advises on interface layouts to optimize clarity, spacing, hierarchy, and usability.

## Activation

- User says "review this layout", "how should I arrange this UI", "spacing advice"
- User shares wireframe or describes interface and wants feedback
- User needs accessibility or hierarchy guidance

## Process

### 1. Analyze Input
- Identify elements, their purpose, and relationships
- Note current hierarchy and visual weight

### 2. Suggest Layout
- Recommend spacing, alignment, grouping
- Prioritize visual hierarchy (most important = most prominent)
- Consider F-pattern or Z-pattern reading flow

### 3. Accessibility Check
- Color contrast considerations
- Touch target sizes
- Screen reader flow

## Output

- Layout recommendations with reasoning
- Element positioning suggestions
- Spacing/alignment guidelines
- Accessibility notes where relevant
