# SCQA Writing Framework

Transforms unstructured ideas into structured, high-engagement content using the SCQA framework. Best for educational material, storytelling, technical explanations, threads, and reports.

## Activation

- User asks to "structure this", "write using SCQA", "make this clearer"
- Content needs logical narrative flow
- User wants thread/article/report with clear progression

## Process

### 1. Situation
- Establish context and current state
- Concise, clear, relevant background

### 2. Complication
- Introduce problem, tension, or disruption
- Create curiosity — why should reader care?

### 3. Question
- Frame the key question audience naturally asks
- Must feel essential and inevitable from the complication

### 4. Answer
- Deliver insight, solution, or recommendation
- Clear, actionable, satisfying

## Output

- SCQA blocks with short paragraphs
- Bullet highlights where useful
- Smooth flow between sections
- No skipped sections, no repetition, conciseness prioritized
